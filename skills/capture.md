# Capture

Cuando el usuario diga algo memorable (trabajo, gente, proyectos, salud, preferencias…):
1. Decide categoría.
2. Llama save_memory con un texto corto y atemporal.
3. Si es algo que pasó hoy, también add_diary_entry.

No conviertas todo el chat en memoria. Solo hechos útiles para el futuro.
Confirma en una frase corta qué guardaste y dónde.
