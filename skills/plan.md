# Plan

Convierte el contexto actual en un plan accionable:
- Objetivo claro
- Pasos numerados y realistas
- Riesgos / dependencias breves
- Siguiente acción inmediata

No ejecutes todavía salvo que el usuario lo pida. Ofrece guardar el plan relevante en memoria o diario si aporta.
